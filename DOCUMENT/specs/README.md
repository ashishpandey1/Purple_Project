# Technical Specifications

## Overview
This folder contains detailed technical specifications and requirements.

## Contents

| File | Description |
|------|-------------|
| `requirements.md` | Functional & non-functional requirements |
| `api-contracts.md` | API schemas, request/response formats |
| `database-schema.md` | Supabase table definitions, migrations |
| `auth-spec.md` | Authentication flows, roles, permissions |
| `realtime-spec.md` | Supabase Realtime subscriptions, events |
| `storage-spec.md` | File storage, buckets, access policies |

## Specification Format
Each spec should include:
1. **Context** - Why this spec exists
2. **Requirements** - Detailed requirements (FR/NFR)
3. **Design** - Technical approach
4. **API/Schema** - Concrete definitions
5. **Testing** - Acceptance criteria
6. **Open Questions** - Unresolved items
