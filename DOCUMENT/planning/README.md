# Planning & Decisions

## Overview
Project planning, roadmap, and Architecture Decision Records (ADRs).

## Contents

| File | Description |
|------|-------------|
| `roadmap.md` | Product roadmap, milestones, timeline |
| `decisions.md` | Architecture Decision Records (ADRs) |
| `adr-template.md` | Template for new ADRs |
| `sprint-planning.md` | Sprint goals, capacity, retrospectives |
| `backlog.md` | Prioritized feature backlog |
| `release-notes.md` | Version history, breaking changes |

## ADR Process
1. Create new ADR from `adr-template.md`
2. Number sequentially: `001-use-supabase-auth.md`
3. Status: `Proposed` → `Accepted` / `Rejected` / `Superseded`
4. Link from `decisions.md` index

## Roadmap Format
```markdown
## Q1 2026
- [ ] Feature A - *In Progress*
- [ ] Feature B - *Planned*

## Q2 2026
- [ ] Feature C - *Research*
```
